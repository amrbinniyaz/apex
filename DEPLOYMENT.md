# Dokploy deployment

- Application: `apex-international-school-web-du25v1`
- Repository: `https://github.com/amrbinniyaz/apex.git`
- Branch: `main` (`master` contains the legacy website)
- Build type: Dockerfile; path `Dockerfile`; context `.`; stage `runtime`
- Container port: `3000`

The Dockerfile builds a standalone Node 24 server with Nitro. Set a domain in
Dokploy with path `/` and port `3000`. Deployments are started manually.

For a local production check, use Node 24:

```sh
npm ci
npm run build:node
PORT=4174 npm run start:node
node scripts/check-runtime.mjs http://localhost:4174
```

To enable enquiry email delivery, set `RESEND_API_KEY`, `ENQUIRY_FROM_EMAIL`,
and `ENQUIRY_TO_EMAIL` in the application environment. Without them, the form
provides its existing email and phone fallback. Never commit these values.

The default local development command remains `npm run dev`. No Sites or
Cloudflare deployment is involved in the Dokploy build.

## Performance checks

The Node build pre-compresses static assets with Brotli and gzip. Hashed bundles
keep their one-year immutable cache policy; `/assets/**` uses a seven-day cache.
Use a new filename when replacing an image or font that must update immediately.

`node scripts/check-runtime.mjs http://localhost:4174` verifies every public route,
responsive image markup, compressed stylesheet responses and static-asset caching.
Run it against `npm run start:node`, since the development server does not represent
production compression or caching.

The school fonts use lossless WOFF2 versions. Regenerate them with
`python3 scripts/prepare-fonts.py` when source TTFs change (requires `fonttools[woff]`).
Responsive WebP files remain generated by `npm run images`; `SchoolImage` emits
their actual width candidates directly instead of using Vinext's custom loader.

The school video loads when its section becomes visible, and hidden activity
images load on interaction. The first-visit arch animation lasts 1.1 seconds.
After deploying performance changes, run a fresh PageSpeed test; old shared
reports retain the original measurements.
